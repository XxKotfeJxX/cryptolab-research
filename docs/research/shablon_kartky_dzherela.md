# Шаблон картки джерела

Створюйте запис для конкретного твердження, специфікації, історичного факту або тестового вектора. Одна публікація може мати кілька записів, якщо вони підтверджують різні твердження. Незаповнені поля позначайте «не встановлено», а не домислюйте.

| Поле | Що записати |
|---|---|
| ID запису і стан | Стабільний ID; `чернетка`, `перевірено` або `готово` |
| Автори джерела | Імена так, як у публікації; окремо редактори, перекладачі та організація |
| Назва й тип | Повна назва; стандарт, стаття, книга, архівний документ, код або набір векторів |
| Версія | Редакція, дата, DOI чи інший стабільний ідентифікатор; URL і дата звернення для вебджерела |
| Місце | Точний розділ, сторінка, таблиця, рисунок, номер вектора чи рядок у файлі |
| Твердження | Що саме джерело дозволяє стверджувати, у власному формулюванні |
| Перевірка | Хто й коли звірив місце у джерелі; чи доступний повний текст; для вектора — точний вхід, параметри й очікуваний вихід |
| Межі | Що джерело не підтверджує; відкриті неоднозначності й обмеження редакції |
| Використання | Посилання на позицію реєстру, розділ праці, профіль або тест, де твердження застосовано |
| Права | Умови використання та атрибуції, якщо відтворюється текст, рисунок, код або дані |

Автор джерела, автор нового тексту й автор Git-коміту — різні ролі. Для власного рисунка або похідного файла записуйте також шлях до незмінного входу, його SHA-256, параметри побудови, версію коду й відповідального за запуск. [Бібліографічна матриця](etap_3_literatura_matrytsia.md) зберігає короткі записи; цю картку використовуйте, коли для твердження потрібна повна перевірка.
