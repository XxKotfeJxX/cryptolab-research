# Гомофонна заміна EN/UK — позиція №29, картка №27

Версія 0.1. Це власна **детермінована навчальна модель**, а не стандартна історична таблиця. Контекст і обмеження класу: [Kopal, HistoCrypt 2019](https://ep.liu.se/en/conference-article.aspx?Article_No=12&issue=158&series=). Для кожної літери абетки задаються два різні однобайтові коди; всі коди різні між літерами. Ключовий файл — рівно `2*m` байтів (для `m=26` або `33`), пара кодів для кожної літери у порядку абетки. Це **бінарний файл**, а не текст hex.

CLI `homophonic encrypt|decrypt --alphabet en|uk --key-file FILE --in FILE --out FILE`. Шифрування приймає лише літери UTF-8, нормалізує регістр і для кожної літери вибирає перший/другий код за парністю її **глобальної позиції** у тексті. Вихід — сирі байти, один на літеру. Розшифрування відновлює великі літери; для кожної позиції обидва коди цієї літери допустимі. Недозволені символи, невідома кодова точка, дубль коду, хибна довжина ключа відхиляються. Порядок вибору повністю передбачуваний і не додає криптографічного захисту.

Стандартного опублікованого вектора для цієї таблиці немає. Тести використовують незалежну Python-модель для конкретного публічного ключа, негативні випадки й крайні довжини; лише round-trip недостатній. До незалежного підтвердження стан — прототип.
