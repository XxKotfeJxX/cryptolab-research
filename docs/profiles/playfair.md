# Плейфер 5×5 EN — позиція №25, картка №24

Версія 0.1. `playfair encrypt|decrypt --key-file FILE --in FILE --out FILE`, лише англійські літери. Ключовий файл містить непорожнє слово ASCII A–Z без пробілів; повтори видаляються, `J` об'єднується з `I`, решта абетки `ABCDEFGHIKLMNOPQRSTUVWXYZ` дописується за порядком. У вхідному тексті регістр нормалізується до верхнього, `J→I`, інші символи відхиляються. Це окремий історичний профіль; український квадрат 33 літер не маскується під нього.

Шифрування ділить текст на пари. Для повторних літер у парі між ними вставляється `X`, а для пари `XX` — `Q`; непарний кінець доповнюється `X` (або `Q`, якщо остання літера `X`). Однаковий рядок зсувається праворуч, однаковий стовпець униз, прямокутник міняє стовпці. Розшифрування приймає парну довжину й зсуває рядок/стовпець назад; заповнювачі **не видаляє автоматично**, бо це неоднозначно. Вихід шифрування може бути довшим за вхід.

Незалежний опублікований приклад: [навчальний матеріал університету, с. 10–11](https://uomustansiriyah.edu.iq/media/lectures/5/5_2021_06_12!05_37_05_PM.pdf): ключ `PLAYFAIREXAMPLE`, `HIDETHEGOLDINTHETREESTUMP` → `BMODZBXDNABEKUDMUIXMMOUVIF`. Правила вставлення у варіанті `XX` і кінцевого `X/Q` — явно визначена тут адаптація; для них перевірка окремим Python-оракулом. Відсутність незалежного українського профілю лишається обмеженням.
