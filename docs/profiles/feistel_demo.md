# Навчальна мережа Фейстеля — позиція №20, картка №23

Версія 0.1. Це **демонстрація конструкції**, а не стандартизований шифр чи кандидат до рейтингу безпеки. Параметри обрані для пояснення оберненості: блок 16 біт, половини `L,R` по 8 біт, чотири раунди, ключ рівно 4 байти `k[0..3]`. Байти блока йдуть у порядку `L||R`; кількість байтів входу кратна двом, доповнення немає.

Раунд `i`: `F(R,k[i]) = rotl8(R,1) XOR k[i]`, `L'=R`, `R'=L XOR F(R,k[i])`. Після четвертого раунду вихід — `L4||R4` без додаткового обміну. Розшифрування проходить раунди у зворотному порядку: `R= L'`, `L=R' XOR F(L',k[i])`. CLI `feistel-demo encrypt|decrypt --key-file FILE --in FILE --out FILE` працює з сирими байтами.

Конструктивний контекст: [Horst Feistel, *Cryptography and Computer Privacy*, 1973](https://www.scientificamerican.com/article/cryptography-and-computer-privacy/) та [FIPS 46-3](https://csrc.nist.gov/pubs/fips/46-3/final) для прикладу іншої конкретної мережі. Для **цієї** мініконструкції зовнішнього стандартного вектора немає: точні виходи перевіряє незалежний короткий Python-оракул, а тест інверсії сам по собі недостатній.
