# Solitaire / Pontifex EN — позиція №27, картка №25

Версія 0.1. Джерело правил і опублікованих векторів: [Bruce Schneier, *The Solitaire Encryption Algorithm*](https://www.schneier.com/academic/solitaire/). Початкова колода — карти 1–52 і джокери A=53, B=54 у цьому порядку. Для кожного виходу: A опускається на одну карту, B на дві; потрійний розріз навколо джокерів; нижній count cut (джокер рахується як 53); карта за індексом верхньої карти (джокер=53) дає число 1–52, джокер пропускається; для 27–52 віднімаємо 26. Ключова фраза застосовує той самий крок колоди для кожної літери, після нього додатковий count cut на її значення A=1…Z=26.

CLI `solitaire encrypt|decrypt --key-file FILE --in FILE --out FILE`: ключовий файл містить ASCII A–Z (може бути порожнім для **публічного тесту неключованої колоди**), вхід — ASCII A–Z; регістр нормалізується до верхнього. Для кожної літери додаємо/віднімаємо число потоку modulo 26 (A=1…Z=26). Пробіли, групування по п'ять і доповнення тут не виконуються: caller подає вже підготовлену послідовність; довжина виходу дорівнює довжині входу. Це явна межа профілю для корпусу.

Опубліковані вектори: порожній ключ, `AAAAAAAAAA` → `EXKYIZSGEH`; ключ `FOO`, п'ятнадцять A → `ITHZUJIWGRFARMW`. Ключ `CRYPTONOMICON` із текстом `SOLITAIREX` має джерельний результат `KIRAKSFJAN`. Тести охоплюють точні виходи, декодування й некоректні символи. Повторне використання тієї самої колоди для різних повідомлень небезпечне; навчальний код не позиціонується як засіб захисту секретів.
