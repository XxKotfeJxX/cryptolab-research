# Поворотна решітка 4×4 — позиція №28, картка №26

Версія 0.1. Це точно визначений навчальний профіль решітки Флейснера. Історичний контекст: [de Leeuw, HistoCrypt 2018](https://ep.liu.se/en/conference-article.aspx?Article_No=12&issue=149&series=); конкретні 4×4 маска й правила нижче є нашим вибором. CLI `grille encrypt|decrypt --alphabet en|uk --key-file FILE --in FILE --out FILE` приймає текст із літер обраної абетки, виводить верхній регістр. Довжина має бути кратною 16; доповнення немає.

Ключовий файл — рівно чотири ASCII hex-цифри `0–9a–f`, наприклад `0125`: кожна задає отвір за індексом `row*4+column`. За чотири повороти за годинниковою стрілкою (`(r,c)→(c,3-r)`) 16 позицій мають з'явитися **рівно один раз**; інакше ключ відхиляється. У кожному повороті символи записуються в отвори за зростанням поточного індексу, після чотирьох поворотів квадрат читається по рядках. Розшифрування читає заповнений квадрат у тому самому порядку поворотів. Блоки незалежні.

Опублікованого вектора саме цього профілю немає. Перевірка — незалежна Python-модель для ключа `0125`, точний 16-символьний вихід, обернена операція, неправильна маска, довжина та українська абетка. До появи незалежного опублікованого або другого перевіреного еталона стан лишається прототипом.
