# Caesar — профіль пілота, картка №19

Статус: **прототип**. Це точний профіль наявного коду, а не історична реконструкція всіх правил письма доби Цезаря.

## Джерела та редакції

- Історичний опис: Светоній, *Divus Julius*, 56.6, англійський переклад J. C. Rolfe у виданні Loeb 1914: https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Suetonius/12Caesars/Julius*.html#56 . Текст описує заміну A на D. Він не визначає сучасний 26-літерний латинський алфавіт, UTF-8, обробку регістру чи сторонніх символів.
- Українська абетка: *Український правопис*, авторизоване видання «Наукова думка», 2019, розділ «Український алфавіт»: https://mon.gov.ua/storage/app/media/zagalna%20serednya/Pravopys.2019/ukr.pravopys-2019.pdf . Український варіант є нашою адаптацією, а не історичним шифром Цезаря.
- Для незалежної перевірки лише англійського зсуву 13: Python 3.14, `codecs.encode(text, "rot_13")`; документація модуля `codecs`: https://docs.python.org/3/library/codecs.html . Інші зсуви й українська адаптація ще потребують незалежного еталона.

## Формат і перетворення

- Вхід та вихід CLI — UTF-8 без BOM і без прихованої нормалізації Unicode; алгоритм обробляє кодові точки, а не байти.
- `en`: `ABCDEFGHIJKLMNOPQRSTUVWXYZ`; `uk`: `АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ`. Малі літери приймаються й перетворюються на великі. Вихід завжди у верхньому регістрі.
- Для індексу `i`, зсуву `s` й довжини абетки `n` шифрування дає `(i+s) mod n`, дешифрування `(i-s) mod n`. Зсув — довільне знакове 64-бітне ціле. Запис `--shift 3` відповідає історичному A→D для `en`.
- `strict` відхиляє всі символи поза обраною абеткою; `passthrough` переносить їх без змін і не додає до числа перетворених літер. Це явна політика сучасного профілю.
- Порожній текст допустимий. Неправильний UTF-8, невідома абетка/політика, символ поза абеткою в `strict`, нецілий зсув і повторені параметри CLI — помилки.
- Зворотне перетворення відтворює **нормалізований верхній регістр**. Початковий регістр не відновлюється.

## Вектори й відкриті перевірки

1. Історичний якір із Светонія 56.6: `A` → `D` при зсуві 3 в `en`.
2. Власний контрольний приклад (не незалежний доказ): `ATTACKATDAWN` → `DWWDFNDWGDZQ` при зсуві 3 в `en`.
3. Незалежний оракул для ROT13: CLI на `en`, `--shift 13`, ASCII-вхід порівнюється з Python `codecs.encode(..., "rot_13")` у `tests/reference/python_oracles.py`; виклик у `tests/test_cli.py`.
4. Український короткий приклад (не незалежний доказ): `АБВГҐ` → `ГҐДЕЄ` при зсуві 3.

Відкрито: незалежна повна перевірка українського профілю та повний вимірювальний журнал. Маніфест корпусу перевіряє `scripts/corpus_stage4.py`; короткий корпусний приклад пройдено. Картка залишається прототипом.
